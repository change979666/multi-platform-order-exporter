项目名称：Lazada, 虾皮, TK三平台电商订单统一提取插件
1. 项目简介
该项目是一个功能强大的Python数据提取工具，专门用于从Lazada、Shopee（虾皮）和TikTok Shop（TK）这三大电商平台的订单页面HTML源代码中，自动化地解析和提取订单数据。它将繁琐的手动复制粘贴工作转变为一键自动化流程，最终将所有抓取到的数据整合并导出为您在第一张图片中指定的标准Excel格式（orders_export.xlsx）。
2. 功能特性
多平台支持：精准适配Lazada、虾皮、TK三大平台的订单页面结构。
字段全覆盖：完整提取SKU、订单号、客户名、订单日期、数量、单价、总价、支付时间、运输方式和运单号等核心信息。
智能化数据处理：
自动从虾皮的订单号中解析出订单日期。
自动处理TK平台合并显示的快递公司与运单号。
对于无单价的平台（虾皮、TK），自动填充默认值0，确保格式统一。
payment_time 和 delivery_time 字段被设定为脚本运行的当前时间，作为订单导出操作的时间戳。
标准化Excel输出：生成与您提供的目标图片格式完全一致的.xlsx文件，便于直接导入其他系统或进行数据分析。
3. 环境准备
确保您的Python环境中已安装以下库：
code
Bash
pip install pandas beautifulsoup4 openpyxl
pandas & openpyxl: 用于创建数据表和导出为Excel文件。
beautifulsoup4: 用于解析HTML源代码的核心库。
4. 如何使用
保存HTML文件：
在浏览器中打开相应平台的“我的订单”或“待处理订单”页面。
右键点击页面，选择“另存为...”。
关键： 在保存类型中，选择“网页，全部 (.html, .htm)”，并确保文件名与代码中指定的名称一致：
Lazada -> Lazada.txt
虾皮 -> 虾皮.txt
TK -> TK.txt
文件放置：将这三个.txt（本质是html）文件与提供的Python脚本放在同一个文件夹下。
运行脚本：直接执行Python脚本。脚本会自动读取文件，提取数据，并生成名为 orders_export.xlsx 的Excel文件。
5. 核心技术解析：各平台提取逻辑详解
以下是针对每个平台，每个数据字段的详细提取逻辑。
5.1. Lazada 平台解析逻辑
总体结构: 订单列表由多个 div.list-item 组成，每个div代表一个独立的订单包裹。
商品结构: 在一个订单包裹内，每个商品由一个 div.order-item 构成。
字段	HTML 源代码示例	CSS 选择器 / 解析逻辑
订单号 (Order Number)	<a data-spm="d_order_number">1038...</a>	a[data-spm="d_order_number"]
客户名称 (Customer Name)	<span class="next-btn-helper">In Finix</span>	div.order-header-chat-box span.next-btn-helper
订单日期 (Order Date)	<a ...>15 Sep 2025 09:05</a>	span.order-field-create-time a
SKU (商品编码)	<span class="">BD34-02</span>	div.order-field-seller-sku span.show-text
数量 (Quantity)	<div class="order-item-count">×1</div>	div.order-item-count，然后去除"×"。
销售单价 (Selling Price)	<span class="number-text-scope" title="55">55</span>	div.order-item-price span.number-text-scope，获取其 title 属性。
订单总额 (Net Selling Price)	<span class="number-text-scope" title="54.25">54.25</span>	div.order-amount-col span.number-text-scope，获取其 title 属性。

5.2. 虾皮 (Shopee) 平台解析逻辑
总体结构: 每个订单包裹由一个 div 元素构成，其 data-testid 属性以 package-card- 开头。
数据特点: 平台不提供单个商品价格，只提供订单总价。
字段	HTML 源代码示例	CSS 选择器 / 解析逻辑
订单号 (Order Number)	<span class="order-sn">... 251017AC38U19T</span>	span.order-sn，提取文本后，去除前缀"หมายเลขคำสั่งซื้อ "。
客户名称 (Customer Name)	<div class="buyer-username">jutapornbewty</div>	div.buyer-username
订单日期 (Order Date)	(无直接字段)	智能解析：从订单号中提取。例如，251017... 的前6位代表年、月、日，解析为 2025-10-17。
SKU (商品编码)	<div class="item-description">... [BD11 BD11-Blue-L×5]</div>	div.item-description，然后提取 [ 和 ] 之间的文本。
数量 (Quantity)	<div class="item-amount">x1</div>	div.item-amount，去除"x"。
销售单价 (Selling Price)	(无)	根据您的要求，此字段固定填充为 0.00。
订单总额 (Net Selling Price)	<div class="total-price">฿230</div>	div.total-price，去除"฿"符号。
运输方式 (Shipping Method)	<div class="fulfilment-channel-name">Flash Express</div>	div.fulfilment-channel-name
运单号 (Tracking Number)	<div class="tracking-number">TH0406...</div>	div.tracking-number
5.3. TikTok Shop (TK) 平台解析逻辑
总体结构: 订单数据在一个 <tbody> 中，每个订单由三个 <tr> 元素组成：
tr.sc-bZgIus: 包含订单头信息（订单号、日期、客户名）。
tr.sc-dPFVfm: 包含所有商品行、价格、物流等核心信息。
tr.sc-cSwLNi: 分隔行。
数据特点: 快递公司和运单号合并在一个字段中，需要拆分。
