## 💡 字段说明

### total_amount（订单总金额）

**显示规则**:
- 每个订单的**第一行商品**显示订单总金额
- 后续商品行该字段为空（避免重复计算）

**示例**:
```
sku              | order_number  | quantity | total_amount
BD71-Black-105CM | 251017ARA0GB6N | 1       | 148.00      ← 第一行显示总金额
BD71-Black-110CM | 251017ARA0GB6N | 2       |             ← 第二行为空
BD71-Black-115CM | 251017ARA0GB6N | 1       |             ← 第三行为空
```

### selling_price（销售单价）

**各平台说明**:
- **Lazada**: 提供单价，显示实际价格
- **Shopee**: 不提供单价，默认为 `0.00`
- **TikTok**: 不提供单价，默认为 `0.00`

## 🎉 更新优势

### 1. 列名更直观
- `total_amount` 比 `net_selling_price` 更简洁
- 英文命名更加规范
- 避免混淆（selling_price 是单价，total_amount 是总金额）

### 2. 便于数据处理
```javascript
// 修改前 - 名称较长
const totalAmount = orders.reduce((sum, order) => 
  sum + parseFloat(order.net_selling_price || 0), 0
);

// 修改后 - 名称简洁
const totalAmount = orders.reduce((sum, order) => 
  sum + parseFloat(order.total_amount || 0), 0
);
```

### 3. 统一命名规范
所有金额字段都使用 `amount` 后缀：
- ~~`net_selling_price`~~ → `total_amount` ✅
- `selling_price` 保持不变（单价用price） ✅

## 🔧 使用说明

### 无需任何配置
插件会自动使用新的列名 `total_amount`

### 导出Excel
1. 重新加载插件（chrome://extensions/ → 刷新🔄）
2. 打开订单页面
3. 点击"提取订单"
4. 导出的Excel将使用新列名

### Excel表头
```
sku | order_number | customer_name | order_date | quantity | selling_price | total_amount
```

## ⚠️ 注意事项

### 向后兼容性
- ❌ 与旧版本导出的Excel**不兼容**（列名不同）
- ✅ 插件功能完全正常
- ✅ 数据内容没有变化，只是列名改变

### 如果使用旧版Excel
如果你有旧版本导出的Excel文件，需要手动将列名改为 `total_amount`：
1. 打开Excel文件
2. 找到 `net_selling_price` 列
3. 双击列标题，改为 `total_amount`
4. 保存文件

或者保留旧列名也不影响使用。
