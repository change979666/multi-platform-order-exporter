# 订单自动展开功能说明

## 📋 概述

本插件已为三个电商平台（虾皮、Lazada、TikTok Shop）添加了**自动展开折叠订单**的功能。在提取订单数据前，会自动展开所有被折叠的多件商品订单，确保提取到完整的订单信息。

**版本**: 1.0.0  
**更新日期**: 2025年10月18日  
**支持平台**: 虾皮（Shopee）、Lazada、TikTok Shop

---

## 🚀 功能特点

### 核心功能
- ✅ **自动识别**: 自动识别每个平台的折叠订单按钮
- ✅ **批量展开**: 一键展开所有折叠的多件商品订单
- ✅ **智能等待**: 自动等待DOM更新完成后再提取数据
- ✅ **错误处理**: 完善的异常处理，即使展开失败也不影响数据提取
- ✅ **调试日志**: 详细的操作日志，方便追踪展开过程

### 执行流程
```
用户点击"提取订单" 
    ↓
步骤1: 展开折叠的订单（根据平台自动选择方法）
    ↓
等待DOM更新（300-1000ms）
    ↓
步骤2: 提取完整的订单数据
    ↓
导出Excel表格
```

## 📌 各平台详细说明

### 1️⃣ 虾皮（Shopee）平台

#### 识别特征
- **按钮选择器**: `.order-item-expand .order-item-expand-text`
- **折叠状态文本**: 包含泰语 `สินค้ารวม`（意为"共X项/件"）
- **示例文本**: `"สินค้ารวม 5 รายการ (5 ชิ้น)"` - 共5项商品（5件）

#### 展开方式
```javascript
// 使用 MouseEvent 模拟点击
inner.dispatchEvent(new MouseEvent('click', { 
  bubbles: true, 
  cancelable: true 
}));
```

#### 等待时间
- **500ms** - 等待展开动画完成

#### 触发条件
- 订单商品数量 ≥ 5件时自动折叠
- 需要点击展开按钮才能看到所有商品

---

### 2️⃣ Lazada平台

#### 识别特征（支持两种按钮样式）

**样式1**: 
- **选择器**: `.order-item-expand .order-item-expand-text`
- **文本特征**: 包含泰语 `สินค้ารวม`（共X项/件）

**样式2**: 
- **选择器**: `.expand-trigger` 或 `.next-btn[data-spm="d_expand"]`
- **文本特征**: 包含泰语 `เพิ่มเติม`（意为"更多"）

#### 展开方式
```javascript
// 样式1: MouseEvent
inner.dispatchEvent(new MouseEvent('click', { 
  bubbles: true, 
  cancelable: true 
}));

// 样式2: 直接调用click()
button.click();
```

#### 等待时间
- **500ms** - 等待展开动画完成

#### 触发条件
- 订单商品数量较多时自动折叠
- Lazada页面可能使用不同的折叠样式

---

### 3️⃣ TikTok Shop平台

#### 识别特征
- **按钮文本**: 包含 `"Show"` + `"more"` + `"item"`
- **示例文本**: 
  - `"Show more items"` - 展开更多商品
  - `"Show 3 more items"` - 展开3件更多商品
  - `"Show 5 more items"` - 展开5件更多商品

#### 展开方式
```javascript
// 直接调用click()方法
button.click();
```

#### 等待时间
- **1000ms** - TikTok需要更长的等待时间

#### 触发条件
- TikTok会自动折叠部分商品
- 需要点击"Show X more items"按钮展开

#### 特殊处理
- 使用 `data-tkExpanded="true"` 标记已处理的按钮，防止重复点击
- 最多点击30次（安全限制）


#### expandTikTokOrders()
```javascript
/**
 * TikTok平台订单展开函数
 * @returns {Promise} 完成后resolve
 */
function expandTikTokOrders() {
  return new Promise((resolve) => {
    // 1. 查找所有可能的按钮元素
    // 2. 过滤包含"Show more item"的按钮
    // 3. 标记并点击展开按钮
    // 4. 等待DOM更新（1000ms）
  });
}
```

### 调用流程

#### 在 `extractOrders` 消息处理中
```javascript
// 步骤1: 先展开所有折叠的订单
switch (platform) {
  case 'lazada':
    await expandLazadaOrders();
    break;
  case 'shopee':
    await expandShopeeOrders();
    break;
  case 'tiktok':
    await expandTikTokOrders();
    break;
}

// 等待DOM完全更新
await new Promise(resolve => setTimeout(resolve, 300));

// 步骤2: 提取订单数据
switch (platform) {
  case 'lazada':
    orders = extractLazadaOrders();
    break;
  case 'shopee':
    orders = extractShopeeOrders();
    break;
  case 'tiktok':
    orders = await extractTikTokOrders();
    break;
}
```

## 🔍 故障排查

### 问题1: 展开功能不工作

**可能原因**:
1. 页面HTML结构变化
2. 按钮选择器失效
3. 文本内容变化（如语言切换）

**解决方案**:
1. 打开浏览器开发者工具（F12）
2. 查看Console日志中的展开信息
3. 检查是否有错误提示
4. 手动点击展开按钮，观察HTML结构

### 问题2: 部分订单未展开

**可能原因**:
1. 等待时间不够
2. 动画未完成就开始提取
3. 页面加载缓慢

**解决方案**:
1. 等待页面完全加载后再点击提取
2. 检查网络连接速度
3. 可以手动先展开部分订单

### 问题3: TikTok展开失败

**可能原因**:
1. TikTok平台更新了HTML结构
2. 按钮文本变化（语言切换）
3. 已达到最大点击次数（30次）

**解决方案**:
1. 检查Console日志
2. 查看按钮实际文本内容
3. 可能需要更新选择器代码

## 🎯 使用建议

1. **确保页面完全加载**: 等待订单列表完全显示后再点击"提取订单"
2. **网络稳定**: 确保网络连接稳定，避免页面加载缓慢
3. **观察日志**: 提取时注意查看调试窗口的日志信息
4. **手动验证**: 第一次使用时，可以先手动展开几个订单，观察效果
5. **分批处理**: 如果订单数量很多，可以分批次提取
