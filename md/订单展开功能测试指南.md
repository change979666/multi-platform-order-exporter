# 订单自动展开功能测试指南

## 🧪 测试准备

1. **重新加载插件**
   - 打开 Chrome 浏览器
   - 进入 `chrome://extensions/`
   - 找到"订单提取插件"
   - 点击刷新按钮 🔄

2. **准备测试页面**
   - 虾皮已发货页面（有5件以上商品的订单）
   - Lazada已发货页面（有多件商品的订单）
   - TikTok订单页面（有"Show more items"按钮的订单）

## 🔍 故障排查清单

### 如果展开功能不工作

#### 检查项1: Console是否有错误
```javascript
// 在Console中手动测试虾皮展开
expandShopeeOrders().then(() => console.log('虾皮展开完成'));

// 测试Lazada展开
expandLazadaOrders().then(() => console.log('Lazada展开完成'));

// 测试TikTok展开
expandTikTokOrders().then(() => console.log('TikTok展开完成'));
```

#### 检查项2: 查看展开按钮是否存在
```javascript
// 虾皮
console.log('虾皮展开按钮:', document.querySelectorAll('.order-item-expand .order-item-expand-text').length);

// Lazada样式1
console.log('Lazada样式1:', document.querySelectorAll('.order-item-expand .order-item-expand-text').length);

// Lazada样式2
console.log('Lazada样式2:', document.querySelectorAll('.expand-trigger, .next-btn[data-spm="d_expand"]').length);

// TikTok
const allBtns = document.querySelectorAll('button, div[role="button"]');
const showMoreBtns = Array.from(allBtns).filter(b => b.textContent.includes('Show') && b.textContent.includes('more'));
console.log('TikTok展开按钮:', showMoreBtns.length);
```

#### 检查项3: 手动模拟点击
```javascript
// 虾皮 - 手动点击第一个展开按钮
const btn = document.querySelector('.order-item-expand .order-item-expand-text');
if (btn) {
  const inner = btn.closest('.order-item-expand-inner') || btn;
  inner.dispatchEvent(new MouseEvent('click', { bubbles: true, cancelable: true }));
  console.log('✅ 手动点击成功');
}

// TikTok - 手动点击第一个"Show more"按钮
const allBtns = document.querySelectorAll('button, div[role="button"]');
const showBtn = Array.from(allBtns).find(b => 
  b.textContent.includes('Show') && 
  b.textContent.includes('more') && 
  b.textContent.includes('item')
);
if (showBtn) {
  showBtn.click();
  console.log('✅ TikTok手动点击成功');
}
```

// 测试虾皮

console.log('样式2按钮:', document.querySelectorAll('.expand-trigger, .next-btn[data-spm="d_expand"]').length);

// 测试TikTok
console.log('\n=== TikTok测试 ===');
const allBtns = document.querySelectorAll('button, div[role="button"], div, span');
const showMoreBtns = Array.from(allBtns).filter(b => {
  const txt = b.textContent || '';
  return txt.includes('Show') && txt.includes('more') && txt.includes('item');

showMoreBtns.forEach((btn, i) => {
