# 虾皮平台兼容性更新说明

## 📋 更新概述

**版本**: 1.1.0  
**更新日期**: 2025年10月18日  
**更新内容**: 虾皮平台同时支持新旧两种HTML结构

---

## 🎯 更新背景

不同虾皮店铺使用不同的HTML结构：
- **旧版店铺**: 使用 `div[data-testid="package-card-"]` 作为订单容器
- **新版店铺**: 使用 `a.order-card` 作为订单容器

插件已更新，**同时兼容新旧两种结构**，无论在哪个店铺都能正常提取订单。

## ✅ 更新内容

### 1. 订单卡片选择器
```javascript
// 旧版: 只支持一种
const orderCards = document.querySelectorAll('div[data-testid^="package-card-"]');

// 新版: 同时支持两种
const orderCards = document.querySelectorAll(
  'div[data-testid^="package-card-"], a.order-card'
);
```

### 2. 商品列表选择器
```javascript
// 旧版: 只支持一种
const items = card.querySelectorAll('div.order-item-infos .item');

// 新版: 同时支持两种
const items = card.querySelectorAll(
  'div.item-list .item, div.order-item-infos .item'
);
```

### 3. 字段提取优化
所有字段提取都使用更健壮的方式：
```javascript
// 订单号
let orderNumberEl = card.querySelector('span.order-sn');
let orderNumber = '';
if (orderNumberEl) {
  orderNumber = orderNumberEl.textContent.replace(/^.*\s+/, '').trim();
}

// 客户名
let customerName = '';
const customerNameEl = card.querySelector('div.buyer-username');
if (customerNameEl) {
  customerName = customerNameEl.textContent.trim();
}

// 总价
let totalPrice = '0.00';
const totalPriceEl = card.querySelector('div.total-price');
if (totalPriceEl) {
  totalPrice = totalPriceEl.textContent.replace('฿', '').trim();
}
```

### 4. 移除物流信息
根据用户需求，已完全移除物流单号提取功能：
```javascript
// ❌ 已移除
// tracking_number: trackingNumber

// ✅ 现在的订单记录
{
  sku: itemData.sku,
  order_number: orderNumber,
  customer_name: customerName,
  order_date: orderDate,
  quantity: itemData.quantity,
  selling_price: '0.00',
  total_amount: itemIndex === 0 ? totalPrice : ''
}
```

## 🎯 使用说明

### 无需任何配置
插件会**自动检测**当前店铺使用的HTML结构，无需用户手动选择或配置。

- ✅ 老店铺（未升级界面）
- ✅ 在不同店铺之间切换

2. 点击插件图标
3. 选择"虾皮"平台
4. 点击"提取订单"
5. 等待自动展开（如有折叠订单）

## 🔍 故障排查

### 问题1: 仍然无法提取订单

**检查步骤**:
1. 运行测试脚本 `test-shopee-structure.js`
2. 查看 Console 输出
3. 确认是否检测到订单容器

**可能原因**:
- 页面未完全加载
- 虾皮又更新了HTML结构
- 不在订单列表页面

**解决方案**:
1. 刷新页面，等待完全加载
2. 确保在 "已发货" 或 "订单管理" 页面
3. 运行测试脚本获取详细信息

### 问题2: 部分字段为空

**检查项**:
- 订单号: 应该显示在页面右上角
- 客户名: 应该显示在订单卡片左上角
- 总价: 应该在订单卡片中部
- SKU: 应该在商品描述的方括号内

**解决方案**:
查看测试脚本输出的"完整测试"部分，确认哪个字段无法提取。

## 📝 技术细节

### 兼容性策略

#### 订单容器
使用逗号分隔的选择器同时匹配两种结构：
```javascript
'div[data-testid^="package-card-"], a.order-card'
```

#### 字段提取
使用 `querySelector` + null 检查，确保不会因为元素不存在而报错：
```javascript
const element = card.querySelector('selector');
if (element) {
  const value = element.textContent.trim();
}
```

#### 商品列表
同时查找两种可能的父容器：
```javascript
card.querySelectorAll('div.item-list .item, div.order-item-infos .item')
```

### SKU提取逻辑（未改变）
1. 从商品描述的方括号内提取
2. 处理 "BD65 BD65-Dark-Brown" 这样的重复格式
3. 如果方括号内有空格，取第一个空格后的部分
4. 回退方案：使用商品名第一个词
